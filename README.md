# 出勤画像メーカー

背景画像と平日5日分の出勤予定から、SNS向けの正方形PNGを作るブラウザ完結ツールです。

## 使い方

1. 背景画像を選びます。
2. 月曜日から金曜日まで、空・満と時間を入力します。
3. 「PNG保存」を選びます。

iPhoneでは、Safariでページを開いて共有ボタンから「ホーム画面に追加」を選ぶと、以後はホーム画面のアイコンから起動できます。PNG保存後に開いた画像は、長押しまたは共有メニューから写真へ保存します。

## データ取扱い

背景画像と入力した出勤予定は端末のブラウザ内で処理します。画像をアップロードしたり、予定を外部へ送信したりしません。状態・時刻・枠線の設定だけをブラウザのlocalStorageに保存します。
